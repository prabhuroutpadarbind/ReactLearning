# Deskware: React Router + Redux Toolkit + MUI

A small shop that shows how routing and global state work together.

- Routing: nested layout, dynamic params, search params, redirects, protected route, 404
- Redux Toolkit: `cart` and `auth` slices, selectors
- MUI: themed AppBar, Cards, Grid, Badge, TextField
- Vitest: slice tests and routing + Redux integration tests

```
npm install
npm run dev
npm test
```
