# React Routing Demo

A small project that demonstrates React Router v6 concepts, tested with Vitest.

## Concepts covered

- Basic routes
- Navigation with `NavLink`, `Link` and `useNavigate`
- Nested routes with `Outlet` and index routes
- Dynamic routes with `useParams`
- Query strings with `useSearchParams`
- Redirects with `Navigate`
- Protected routes with redirect back to the original page
- 404 catch-all route
- Route tests with `createMemoryRouter`

## Run

```
npm install
npm run dev
npm test
```
